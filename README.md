# Cybersecurity Lab & Exploit Exercises 🛡️💻
Este repositorio contiene la documentación detallada (writeups), herramientas y scripts desarrollados durante la resolución de máquinas de entrenamiento en plataformas como VulnHub y proyectos de infraestructura segura.

## 👤 Perfil Técnico
*   **Enfoque**: Seguridad Ofensiva, Análisis SOC y Arquitectura de "Defense in Depth".
*   **Sistemas Operativos**: Especialista en entornos Linux (Parrot Security OS, Debian, AlmaLinux).
*   **Herramientas**: Neovim (LazyVim/NvChad), Kitty terminal y bspwm.

## 📂 Proyectos: VulnHub

### 🏢 IMF (Intermediate)
*   **Estado**: Completada ✅
*   **Vectores de Ataque**: Bypass de WAF, RCE mediante subida de archivos y Port Knocking.
*   **Escalada de Privilegios**: Análisis de memoria y explotación de Buffer Overflow en binarios de C.
*   **Habilidades Clave**: Estabilización de TTY, uso de `gdb-peda` y desarrollo de exploits en Python.

## 📑 Metodología
1.  **Reconocimiento**: Escaneo de servicios con Nmap y enumeración de directorios.
2.  **Análisis de Vulnerabilidades**: Identificación de fallos en aplicaciones web y servicios locales.
3.  **Explotación**: Desarrollo de payloads y obtención de acceso inicial.
4.  **Post-Explotación**: Auditoría interna del sistema para elevar privilegios a Root.
5.  **Reporte y Mitigación**: Documentación de los hallazgos y propuestas de endurecimiento (Hardening).
